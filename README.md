# AI Threat Detection System

An end-to-end **Cyber Threat Detection** system that uses a deep learning LSTM model trained on the UNSW-NB15 network intrusion dataset to classify network traffic as **Normal** or **Attack** in real time. Supports both binary classification and multiclass attack-category prediction.

---

## System Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                    RAW NETWORK TRAFFIC                       │
│              (UNSW_NB15_training-set.csv)                    │
└───────────────────────┬─────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────────┐
│               PREPROCESSING  (preprocess.py)                 │
│                                                              │
│  1. Column validation & automatic detection                  │
│  2. Missing value imputation (median / mode)                 │
│  3. Categorical encoding   → saved as  encoder.pkl          │
│  4. Feature normalisation  → saved as  scaler.pkl           │
│  5. LSTM reshape  (samples, 1, features)                     │
│  6. Multiclass attack-category labels  (optional)            │
└───────────────────────┬─────────────────────────────────────┘
                        │  X_train / X_test / y_train / y_test
                        ▼
┌─────────────────────────────────────────────────────────────┐
│                  LSTM MODEL  (lstm_model.py)                  │
│                                                              │
│   Input (timesteps=1, features=N)                            │
│     → LSTM(128)  + BatchNorm + Dropout(0.3)                  │
│     → LSTM(64)   + BatchNorm + Dropout(0.3)                  │
│     → Dense(32, ReLU)        + Dropout(0.2)                  │
│     → Dense(1, sigmoid)   ← binary mode                      │
│       OR Dense(10, softmax)  ← multiclass mode               │
└───────────────────────┬─────────────────────────────────────┘
                        │  EarlyStopping · ModelCheckpoint
                        │  ReduceLROnPlateau
                        ▼
┌─────────────────────────────────────────────────────────────┐
│                    TRAINING  (train.py)                       │
│                                                              │
│  Saves:  saved_models/lstm_threat_detection.h5               │
│          results/graphs/training_history.png                 │
│          results/graphs/accuracy_curve.png                   │
│          results/graphs/loss_curve.png                       │
│          results/graphs/confusion_matrix.png                 │
│          results/reports/classification_report.txt           │
│          logs/detection.log                                  │
└───────────────────────┬─────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────────┐
│                  PREDICTION  (predict.py)                     │
│                                                              │
│  Input : X_test.npy  OR  any new traffic CSV                 │
│  Output: Normal / Attack + Confidence %                      │
│          (or attack category in multiclass mode)             │
└─────────────────────────────────────────────────────────────┘
```

## Dataset Setup

### Download UNSW-NB15

| Source   | Link |
|----------|------|
| Official | https://research.unsw.edu.au/projects/unsw-nb15-dataset |
| Kaggle   | https://www.kaggle.com/datasets/mrwellsdavid/unsw-nb15 |

### Place CSV files

Download and copy both files into the `dataset/` folder:

```
dataset/
├── UNSW_NB15_training-set.csv
└── UNSW_NB15_testing-set.csv
```

> If only the training CSV is available, the preprocessor will automatically split it 80/20 (stratified) into train and test sets.

### Dataset Overview

| Property     | Details                                    |
|--------------|--------------------------------------------|
| Records      | ~2.5 million network connections           |
| Features     | 49 features per record                     |
| Binary label | 0 = Normal,  1 = Attack                    |
| Attack types | 9 categories (see table below)             |

### Attack Categories (Multiclass)

| Class | Category       | Description                                 |
|-------|---------------|---------------------------------------------|
| 0     | Normal        | Legitimate network traffic                  |
| 1     | Analysis      | Port scans, HTML file penetration           |
| 2     | Backdoor      | Bypass authentication mechanisms            |
| 3     | DoS           | Denial of Service attacks                   |
| 4     | Exploits      | Known vulnerability exploitation            |
| 5     | Fuzzers       | Random/invalid data injection               |
| 6     | Generic       | Block cipher algorithm attacks              |
| 7     | Reconnaissance| Probing and scanning                        |
| 8     | Shellcode     | Small payload for shell execution           |
| 9     | Worms         | Self-replicating malware                    |

## Configuration

All paths and hyperparameters are in `config.py`. Edit that single file to change any setting.

| Variable             | Default                                        | Description                       |
|----------------------|------------------------------------------------|-----------------------------------|
| `TRAIN_CSV`          | `dataset/UNSW_NB15_training-set.csv`           | Training data path                |
| `TEST_CSV`           | `dataset/UNSW_NB15_testing-set.csv`            | Testing data path                 |
| `MODEL_PATH`         | `saved_models/lstm_threat_detection.h5`        | Saved model path                  |
| `LOG_FILE`           | `logs/detection.log`                           | Cybersecurity event log           |
| `EPOCHS`             | `30`                                           | Max training epochs               |
| `BATCH_SIZE`         | `256`                                          | Samples per gradient update       |
| `LEARNING_RATE`      | `0.001`                                        | Adam initial learning rate        |
| `EARLY_STOP_PATIENCE`| `5`                                            | Epochs before early stopping      |
| `PREDICTION_THRESHOLD`| `0.5`                                         | Binary classification threshold   |

## LSTM Model Architecture

| Layer                  | Output Shape       | Notes                         |
|------------------------|--------------------|-------------------------------|
| LSTM (128 units)       | (None, 1, 128)     | `return_sequences=True`       |
| BatchNormalization     | (None, 1, 128)     | Stabilises training           |
| Dropout (0.3)          | (None, 1, 128)     | Prevents overfitting          |
| LSTM (64 units)        | (None, 64)         | `return_sequences=False`      |
| BatchNormalization     | (None, 64)         |                               |
| Dropout (0.3)          | (None, 64)         |                               |
| Dense (32, ReLU)       | (None, 32)         | Hidden representation         |
| Dropout (0.2)          | (None, 32)         |                               |
| Dense (1, sigmoid)     | (None, 1)          | Binary output                 |
| — OR —                 |                    |                               |
| Dense (10, softmax)    | (None, 10)         | Multiclass output             |

**Optimizer:** Adam &nbsp;|&nbsp; **Loss (binary):** Binary Crossentropy &nbsp;|&nbsp; **Loss (multiclass):** Sparse Categorical Crossentropy

### Overfitting Prevention

- Dropout layers (0.2–0.3) after every LSTM and Dense block
- BatchNormalization after LSTM blocks
- EarlyStopping (`patience=5`) monitors `val_loss`
- ReduceLROnPlateau halves the learning rate after 3 stagnant epochs

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `FileNotFoundError: dataset not found` | Download UNSW-NB15 CSVs and place in `dataset/` |
| `FileNotFoundError: X_train.npy not found` | Run `python preprocessing/preprocess.py` first |
| `FileNotFoundError: model not found` | Run `python model/train.py` first |
| `Label column 'label' not found` | Check your CSV has a `label` column (case-insensitive) |
| Low accuracy on custom CSV | Ensure column names match UNSW-NB15 format |
| `--multiclass` shows no categories | Dataset must contain `attack_cat` column |
